# note-app

Minimal GoodNotes-style notebook app for iPad and Mac: folders of notebooks with blank/lined/grid/dotted pages or imported PDFs (import takes folders too, keeping their structure; notebooks, boards and text documents from another copy of the app, e.g. the free build's On My iPad › Notes, come in whole, ink and all), Apple Pencil ink with a GoodNotes-style top bar (pen, highlighter, eraser (precision, standard or whole-stroke), lasso, shapes (freehand shapes recognized when you lift, elbow and curved connectors, rectangle, ellipse, triangle, diamond, rounded rectangle), typed text boxes with arrows, laser pointer (a dot, or a line that fades away; nothing is kept), colors, widths, undo/redo; Pencil double-tap and two/three-finger tap undo/redo), draw and hold (keep the Pencil still on the page for half a second during a pen or highlighter stroke and the stroke becomes a straight line (or a few joined ones), triangle, quadrilateral, rectangle, ellipse or circle, which turns and resizes with the Pencil until you lift it), lists in text boxes (Return continues a list and ends it on an empty item; with the Text tool, tap ☐ to tick it), new pages that repeat the paper of the page before them (Add Page, or pull up past the last page and let go), clear or delete a page from the ⋯ menu, PDF export.

Alongside notebooks, the library holds text documents and Excalidraw boards. A text document (+ → New Text Document) is a title over one column of typed text, as in GoodNotes: type `/` at the start of a line or after a space for Date, Time, Checklist, Bulleted List or Numbered List (a list under the cursor narrows to the commands matching the letters you type; tap one, or press Return for the highlighted first match); Return continues a list and ends it on an empty item, and tapping ☐ ticks it. It saves as you type, and search finds its text. A board (+ → New Excalidraw Board) is an infinite whiteboard running Excalidraw's own editor, offline, with all of its tools. A board saves itself as you draw; its menu's Open loads a `.excalidraw` file into it, and Save to… and Export Image save files wherever you pick. Saved shapes (Excalidraw's library) are shared by every board.

The library is a folder: in the App Store build, the app's iCloud container (iCloud Drive › Notes in the Files app); in the free-account builds of `scripts/ipad.sh` and `scripts/mac.sh`, and whenever iCloud is off, the app's Documents (On My iPad › Notes). Folders inside it are plain directories and can nest; an optional `.folder.json` holds the folder's color and icon. A notebook is a directory containing `meta.json` (title, paper type, page ids in order, page to reopen at, bookmarked pages, outline entries), `doc.pdf` (page backgrounds), `ink/<page id>.data` (one `PKDrawing` per page, so saving touches only the pages you edited) and `items/<page id>.json` (typed text boxes and the arrows between them). A text document is a directory containing `meta.json` (its title) and `text.txt` (its text; a list item is a line starting with `☐ `, `☑ `, `• ` or `1. `), plus `cover.jpg`. A board is a directory containing `meta.json` (its title) and `board.excalidraw` (the scene, in Excalidraw's own file format, so excalidraw.com opens it), plus `cover.jpg` once it has been drawn on; search finds boards by title. The shared Excalidraw library is `.library.excalidrawlib` at the top of the library. Optional notebook files: `paper.pdf` (the paper a new page gets when the page before it isn't plain paper but a page of a document), and two caches rebuilt after edits: `cover.jpg` (page 1 for the library) and `search.json` (each page's PDF text, typed text and handwriting read with Vision, for library search). Device backups include the app's Documents.

## Sync between devices

The App Store build (team and bundle id `com.ashishsharma.notes` in `project.yml`, signed with the iCloud container `iCloud.com.ashishsharma.notes`) keeps the library in iCloud, so every device signed in to the same Apple Account has it; there's nothing to set up. Signing it needs a paid developer team: a free one can't sign iCloud, so the free-account builds keep their library on the device. The app asks iCloud for every file it hasn't downloaded yet; a document still downloading shows "Downloading…" in the library and in its tab. An open document reopens from disk when another device changes it, and saves are coordinated with iCloud. Editing the same document on two devices at once isn't merged: for each file, one device's save wins.

## Run on your iPad

1. Install Xcode from the App Store, then `brew install xcodegen`.
2. Install Node (`brew install node`), then in this folder `scripts/board.sh` (builds the board editor), `xcodegen`, and `open Notes.xcodeproj`.
3. Target **Notes → Signing & Capabilities**: the project is set up for the App Store build, which needs the paid team in `project.yml` (it signs iCloud). With a free Apple ID, use `scripts/ipad.sh install` instead (below), which signs without iCloud.
4. Plug in the iPad, select it as the run destination, press ⌘R. On the iPad, trust the developer in Settings → General → VPN & Device Management.

With a free Apple ID the install expires after 7 days; rebuild to renew. A paid developer account extends that to a year.

## Run on your Mac

`scripts/mac.sh` builds the Mac version (Mac Catalyst) and installs it as `~/Applications/Notes.app`. It's signed to run on this Mac only, so it doesn't expire, and it needs no developer account. Its library is in `~/Library/Containers/com.ashish.Notes/Data/Documents`; this build has no iCloud (see Sync).

## Scripts

- `scripts/testflight.sh` archives the iPad and Mac apps, named draw-note ("Notes" is Apple's), signed by the team in `project.yml` and uploads both to App Store Connect for TestFlight, each with a build number from the time. Run it as `ASC_KEY_ID=… ASC_ISSUER_ID=… scripts/testflight.sh`; what it needs set up once (an App Store Connect API key, the distribution and installer certificates, two App Store provisioning profiles) is listed at the top of the script. `.gitignore` keeps `.p8` keys out of git.
- `scripts/ipad.sh install` builds with the free personal team (as `com.ashish.Notes`, without iCloud), signs and installs on the iPad (USB or same Wi-Fi). `schedule` / `unschedule` manage a daily 21:00 reinstall that keeps the free-account install from expiring; log in `~/Library/Logs/notes-install.log`.
- `scripts/goodnotes-import.sh BACKUP_DIR [--install]` converts a GoodNotes backup (folders of `.goodnotes` files) into notebooks under `build/goodnotes-import/GoodNotes`, keeping the folder tree, and with `--install` copies it into the app's Documents on the iPad of the free-account build (for the App Store build, copy the folder into iCloud Drive › Notes instead). Handwriting, highlighter, shape-tool shapes and lasso moves become editable ink; paper templates, imported PDFs and images become page backgrounds; text boxes and connectors become editable text boxes and arrows; GoodNotes text documents (typed text, stored as Yjs documents and read by `tools/Yjs.swift`) become text documents, their first line the title, with checklists, numbered and bulleted lists and dates written the way slash commands write them, and tables row by row; typed text on a page of a notebook becomes text boxes, continued over as many pages as it needs. Each notebook's page 1 is compared with GoodNotes' own thumbnail, and side-by-side images of low matches go to `build/goodnotes-import/low-match/`. The format notes are at the top of `tools/GoodNotesImport.swift`.
- `scripts/board.sh` builds the board editor (`board/`: Excalidraw, pinned in `board/package.json`, plus the page that connects it to the app) into `build/board`, which the app bundles; `ipad.sh` and `mac.sh` run it.
- `scripts/check.sh` runs `Tests/NotebookCheck.swift`, which exercises page insert/delete, ink persistence, boards and text documents in the library, and the sync helpers (iCloud placeholders, telling another device's saves from the app's own) by compiling `Notes/Notebook.swift` for Mac Catalyst.
